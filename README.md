# ARGEDA AI — Android-приложение

Приложение для сайта ai.argeda.ru: сайт внутри приложения плюс то, чего нет в браузере.
Пакет `ru.argeda.ai`, Android 7.0 и новее, без сторонних библиотек.

## Что умеет
- Вход сохраняется, загрузка файлов и фото с камеры, микрофон.
- Скачанные картинки и видео — в галерею, остальное — в «Загрузки / ARGEDA AI».
- Музыка играет в фоне и на экране блокировки, не рвётся при переходах.
- Оплата внутри, чужие ссылки — во внешних приложениях.
- PDF и документы открываются после скачивания, печать, «Поделиться».
- Автообновление: раз в 6 часов читает `versiya.json` последнего выпуска в Releases этого репозитория (запасной путь — ai.argeda.ru/prilozhenie/).

## Сборка
GitHub Actions собирает APK на каждый push в `main` (файл в Artifacts).
Новая версия для людей:
1. В `app/build.gradle` поднять `versionCode` (на 1) и `versionName`.
2. Поставить тег `vX.Y` с коротким описанием: `git tag -a v1.7 -m "Что нового" && git push --tags`.
3. Actions соберёт, подпишет и выложит в Releases `ARGEDA-AI.apk` и `versiya.json`.
4. Приложения у людей обновятся сами в течение 6 часов. Для сайта (страница «Скачать») сервер может скопировать оба файла в `public/prilozhenie/`.

## Ключ подписи
Хранится только в секретах репозитория: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
В репозиторий ключ не кладём. Тем же ключом подписаны все версии — менять его нельзя, иначе обновление поверх не встанет.
